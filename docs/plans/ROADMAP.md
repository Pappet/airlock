# Airlock Roadmap

## Vision
Airlock aims to be the universal standard coordination tool for high-discipline software development with AI agents and human engineers.

## Milestones

### Milestone 1: Local Task CLI (v0.1.0)
- Single-binary CLI for managing work packages.
- Zero merge conflicts across concurrent branches and git worktrees.
- Direct replacement for manual editing of monolithic planning markdown files.

### Milestone 2: Agent Protocol & MCP (v0.2.0)
- Native MCP server integration.
- Sub-200-token work package retrieval.
- Automated airlock question routing between implementation and specification agents.

### Milestone 3: Web Dashboard & Visual Board (v0.3.0)
- Embedded zero-dependency web UI.
- Visual Kanban board and dependency DAG.
- Real-time session monitoring and human-in-the-loop task queues.

### Milestone 4: Multi-Project & Cloud/Team Sync (v0.4.0)
- Optional remote peer-to-peer or server synchronization for distributed developer teams.
- Plugin hooks for CI/CD status reporting.
